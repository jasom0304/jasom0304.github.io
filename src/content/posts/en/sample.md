## How to format

A blank line starts a new paragraph. A line that starts with `##` is a heading.

> A line that starts with `>` is a quote. Good for a sentence worth keeping.

To add a photo, put the image file next to this post and write `![caption](./photo-name.jpg)`.

Wrap text in two asterisks for **bold**, and use square then round brackets for a [link](https://example.com).
